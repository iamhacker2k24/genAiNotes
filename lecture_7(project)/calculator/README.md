# Modern Calculator

A sleek, modern, and responsive web calculator built with vanilla HTML, CSS, and JavaScript.

## Features

- **Modern UI**: Clean dark theme interface with smooth animations and responsive layout.
- **Arithmetic Operations**: Addition (`+`), subtraction (`-`), multiplication (`×`), and division (`÷`).
- **Additional Functions**:
  - Percentage calculation (`%`)
  - Clear all (`AC`)
  - Backspace / Delete last digit (`DEL`)
  - Floating point decimal precision handling
  - Division by zero alert
- **Full Keyboard Support**: Seamlessly operate using your physical keyboard or numpad.
- **Zero Dependencies**: Lightweight, standalone, and runs directly in any modern browser.

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0` - `9` | Input numbers |
| `.` | Input decimal point |
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide |
| `%` | Percentage |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last digit |
| `Escape` | Clear display (AC) |

## Getting Started

### Prerequisites

No build tools or external dependencies are required. Any modern web browser (Chrome, Firefox, Safari, Edge) is sufficient.

### Running Locally

1. Clone or download the repository.
2. Navigate to the `calculator` folder:
   ```bash
   cd calculator
   ```
3. Open `index.html` directly in your web browser:
   - Double-click `index.html` in your file explorer, or
   - Use a local development server such as VS Code Live Server or:
     ```bash
     npx serve .
     ```
